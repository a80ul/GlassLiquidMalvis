# Changelog

## v1.0.0, 2026-09-23

Modified release based on Aurora Glass by burgess1202
(https://github.com/burgess1202/aurora-glass-seelen-ui, AGPL-3.0).

- Frozen all continuously running keyframe animations into still frames.
- Removed saturate and brightness filters, forced compositor layers and
  small surface blurs. Toolbar keeps a single blur surface.
- Added settings groups in English and Indonesian: freeze all motion,
  compact toolbar, toolbar font, quality preset (Potato, Balanced, High),
  extreme saver mode and dock media art modes.
- Renamed the theme to GlassLiquidMalvis with an original GLM portrait.
- Added LICENSE, NOTICE.md, CREDITS.md and this changelog for
  modification transparency.
